| **Feature**                          | **const (Constant)**                                                                      | **readonly (Read-Only)**                                                                                           |
| ------------------------------------ | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Evaluation Time**                  | Compile-time constant                                                                     | Run-time constant                                                                                                  |
| **Initialization**                   | Must be initialized at the time of declaration                                            | Can be initialized at declaration or inside a constructor                                                          |
| **Storage / Memory**                 | No separate memory per instance; value is embedded directly into the compiled IL          | Stored as part of the instance; `static readonly` uses static storage                                              |
| **Allowed Types**                    | Primitives (`int`, `double`, `string`, etc.), enums, or `null`                            | Any data type, including classes, structs, and objects                                                             |
| **Cross-Assembly Behavior**          | If the value changes in a DLL, dependent DLLs must be **recompiled** to see the new value | If the value changes in a DLL, dependent DLLs **do not need recompilation**; they pick up the new value at runtime |
| **Can change after initialization?** | ❌ No                                                                                      | ❌ No, after constructor execution                                                                                  |
| **Can be instance-level?**           | ❌ No; `const` is implicitly static                                                        | ✅ Yes, or use `static readonly`                                                                                    |
| **Typical Use**                      | Fixed values known at compile time, e.g. `PI`, status codes                               | Values determined at runtime but should not change afterward                                                       |
