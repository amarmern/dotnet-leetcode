Domain project
The Domain is the most independent layer.
Domain/
 ├── Entities/
 │    └── Order.cs
 ├── ValueObjects/
 ├── Enums/
 ├── Exceptions/
 └── DomainServices/

Domain should NOT depend on:
 ❌ EF Core
❌ ASP.NET Core
❌ Redis
❌ Kafka
❌ SQL Server
❌ Controllers

Application project

Application contains use cases/application business logic.

Application/
 ├── Interfaces/
 │    ├── IOrderRepository.cs
 │    └── IPaymentService.cs
 │
 ├── Orders/
 │    ├── CreateOrder/
 │    └── GetOrder/
 │
 ├── DTOs/
 └── Validators/

 API project
The API is the entry point.

Api/
 ├── Controllers/
 ├── Middleware/
 ├── Filters/
 ├── Extensions/
 └── Program.cs

 THe thumb rules are

 Domain
  ↓
Minimal dependencies

Application
  ↓
Business/application concerns

Infrastructure
  ↓
EF Core / Redis / Kafka / External SDKs

API
  ↓
HTTP / Swagger / Auth / Middleware
